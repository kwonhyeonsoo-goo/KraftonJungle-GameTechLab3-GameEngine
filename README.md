# Weekly Engine History

크래프톤 정글 게임 테크 랩에서 매주 자체 엔진을 만든 기록을 한 저장소에 모았습니다.

- `DynamicRopeDocs`는 통합 대상에서 제외했습니다.
- 각 주차 저장소의 원격 기본 브랜치(`main` 또는 `master`) 전체 이력을 해당 폴더 아래로 옮겼습니다.
- 작성자/커미터 이름과 이메일, 작성 시각, 커밋 메시지, 부모 관계를 유지했습니다.
- 경로 이동과 에셋 정리로 커밋 SHA 및 기존 서명은 변경되었습니다.
- GitHub 게시를 위해 전체 이력에서 50 MiB 이상 파일, 음원, 출처가 불명확한 모델과 그 종속 텍스처를 제거했습니다.
- 세부 삭제·유지 기준과 Week 14 검토 결과는 [ASSET_POLICY.md](ASSET_POLICY.md)에 기록했습니다.

## 공개 에셋

팀이 만든 `.uasset`과 자체 바이너리, 독립 이미지·텍스처, 폰트·영상·압축 파일은 유지했습니다. 음원과 출처가 불명확한 FBX/OBJ 및 종속 텍스처는 과거 커밋까지 제거했습니다. 이 분류는 법률 검토를 대신하지 않으므로 재배포 전 [공개 에셋 정책](ASSET_POLICY.md)의 주의사항을 확인해 주세요.
